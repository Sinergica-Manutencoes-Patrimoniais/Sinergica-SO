# Modelo de conteúdo

Sem persistência nova. Assunto estático: `id` único, `titulo`, `resumo`, `palavrasChave`, `quando`, `passos` (título/texto), `conferir` (lista), `duvidas` (pergunta/resposta), `relacionados` (IDs existentes). IDs ASCII, prefixados por `pcm-` no endereço. Sem dados pessoais/credenciais.
