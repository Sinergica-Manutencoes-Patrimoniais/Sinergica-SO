# ADR-0180 — Classificação preliminar de linhas de estrutura

## Decisão

Preparar classificação de conferência sem escrita oficial: rejeitada e decidida são derivadas das decisões existentes; linha sem decisão e com código igual a um cadastro do mesmo tipo/Cliente é candidata a alteração; sem código ou com colisão ambígua permanece para conferência; um código ainda não encontrado e nome sem igual no Cliente indica apenas candidata a nova. Diagnóstico anterior continua disponível. A consulta não resolve equivalência nem aprova atualização e fica revogada.

## Limites

Não é classificação definitiva: não prova unicidade global, igualdade funcional, Local ou hierarquia, nem cobre código de Grupo. Um nome repetido pode ser legítimo e aliases exigem conferência. Revalidar no servidor no momento da decisão. Template CSV é estático e não carrega dados de terceiros; XLSX permanece pendente. Sem aplicação ou testes.
