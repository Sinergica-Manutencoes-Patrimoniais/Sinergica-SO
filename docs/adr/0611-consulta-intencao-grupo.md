# ADR-0611 — Consulta de intenção de OS para Grupo

Consulta autorizada por Cliente apresenta intenção, decisão e vínculo declarado associados à ocorrência, com quantidade histórica em texto. Ausência significa somente ausência nos registros consultados; não é prova de que não exista OS fora deles. O gate permanece desligado e não há concessões.

As decisões não criam OS nem autorizam execução; concorrência, correção de decisão imutável, testes e homologação permanecem pendentes.
