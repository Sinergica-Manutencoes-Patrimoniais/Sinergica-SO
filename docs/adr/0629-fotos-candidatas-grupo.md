# ADR-0629 — Fotos candidatas de OS do Grupo

Consulta autorizada retorna somente notas da OS vinculada com objeto JPEG/PNG existente em bucket privado e Cliente coincidente. A seleção não comprova autoria, conteúdo ou pertinência técnica; o comando de registro revalida a origem. Gate e permissões permanecem fechados; testes e revisão ainda são necessários.
