# ADR-0444 — Conferência informativa de Planos relacionados

Status: preparada, gate fechado, não aplicada nem homologada. Compara, por Rotina e versão explicitamente selecionada, IDs de alvo e questionário, intervalo e data-base com os campos conhecidos do Plano Preventivo do mesmo Cliente. Para versão aprovada usa snapshot; para rascunho usa fonte mutável. A ausência de dados é indeterminada. Paginação não congela fontes e os campos não esgotam condições contratuais.

Nenhuma igualdade ou divergência decide equivalência, deduplicação, elegibilidade nem alteração de gerador. Não altera fontes nem aprova a relação; requer testes e revisão adversarial antes de habilitar.
