# ADR-1574 — Listar ciclos para reserva

As listas de integração anteriores omitem ciclos já vinculados e impedem revisar ou reservar uma ponte existente. A nova leitura autenticada lista preparadas com identidade canônica, vinculadas ou não, por Cliente, Plano e modo, paginadas. Não cria vínculo nem presume equivalência. A decisão continua exigindo conferência e revalidação das fontes pelo comando próprio.
