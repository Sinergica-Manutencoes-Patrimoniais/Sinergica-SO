# ADR-0264 — Movimentação restrita de Grupo Quantitativo

O comando integral de Grupo já permite trocar Local e registra retratos auditáveis. Prepara-se operação específica, privada e desligada, que muda apenas o Local para outro ativo do mesmo Cliente, com motivo, comparação de revisão, idempotência e registro antes/depois. Quantidade, identidade, categoria, características e Sistema são preservados; Sistema é funcional e não representa posição física.

O comando não substitui a edição existente. Ativação depende de testes, revisão das travas e validação integrada com os consumidores da estrutura técnica.
