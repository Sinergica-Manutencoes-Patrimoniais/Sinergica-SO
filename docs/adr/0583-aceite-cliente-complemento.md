# ADR-0583 — aceite do Cliente para valor adicional

Status: bloqueado para efetivação; gates fechados, não aplicado nem homologado. A decisão 0795 é expressamente autorização comercial interna, não aceite do Cliente. O aceite versionado da proposta original registra o valor daquela proposta, mas não comprova aprovação do valor adicional do complemento. As fontes examinadas não estabelecem se cada contrato exige novo aceite nem registram um aceite específico desse valor.

Enquanto o gate de exigência de autorização estiver ativo, a conferência de novo complemento de proposta fica bloqueada por ausência de prova contratual/aceite adicional; recuperação idempotente de comando já concluído não é nova conferência. Não se presume que todo contrato exija novo aceite: será necessário comprovar regra aplicável e, quando exigida, fonte autenticada de aprovação do complemento, sem reaproveitar indevidamente a proposta original. O diagnóstico somente informa autorização interna e prova externa desconhecida. Sem cobrança ou alteração de valores.
