# ADR-0641 — Diagnóstico de códigos informados para Grupos

Status: proposta; gate fechado, não homologada.

Consulta paginada e autorizada conta possíveis correspondências do código informado de Grupo com Sistemas, Componentes/Equipamentos e aliases do mesmo Cliente, além de outras linhas de Grupo no lote. Não revela códigos ou dados de outros Clientes, nem define unicidade, atribui código ou cria alias. Normalização aqui serve apenas para alertar e não altera o valor original.

Ausência de correspondência neste escopo não demonstra ausência de colisão global ou define namespace. Atribuição oficial e integração com os guardas permanecem pendentes de definição e revisão. Gate/RPC fechados; testes e aplicação pendentes.
