# ADR-0281 — Indícios rastreáveis de ocorrências e OS de Grupo

Prepara-se consulta privada, desligada e somente de contagem para ocorrências preparadas cujo alvo explícito é o Grupo e OS distintas referenciadas por pendências técnicas cujo alvo explícito é o mesmo Grupo. Não se infere estado operacional nem abrangência integral a partir dessas ligações; registros ausentes não provam inexistência. A consulta exige gestão de cadastro, gestão de Plano e validação de execução para o Cliente.

Não altera dados, programação ou OS. Revisão de permissões, integridade de origem e testes são pré-requisitos para ativação.
