# ADR-1576 — Reserva de Visita futura existente

O PCM escolhe explicitamente uma Visita contratual regular existente e um índice legado. A fotografia compara Plano, versão aprovada, Rotina, alvo, série, semana, regra, data e fontes declaradas; não pressupõe equivalência nem completude externa. A reserva usa a identidade canônica da Visita, sem criar Visita, ocorrência ou OS. Feriado declarado, vínculo/estado alterado e efeito incerto exigem reconciliação. A guarda 1045 permanece intacta; API e UI exigem revisão e ensaio em clone antes de exposição.
