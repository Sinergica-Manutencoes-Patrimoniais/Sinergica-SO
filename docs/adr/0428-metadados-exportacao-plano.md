# ADR-0428 — Metadados para exportação

Status: preparado, gate desligado, não aplicado nem homologado. Consulta autorizada informa identificadores do Cliente, Plano e versão aprovada, nome do Plano, número, vigência e quantidade de Rotinas quando o snapshot contém um array. Não expõe custos, não gera artefato e não representa cronograma operacional. O indicador de array disponível não prova validade integral do conteúdo. Exige testes e revisão antes de ativação.
