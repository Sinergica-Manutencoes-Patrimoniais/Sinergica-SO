# Levantamento funcional do Sinérgica SO

Materiais entregues para Fabrício e Aline, com referência em 14/10/2026:

- [Markdown para consulta e uso com IA](levantamento-funcional.md): 83 capacidades,
  regras, operação e 22 jornadas propostas de validação.
- [HTML de apresentação offline](apresentacao-funcional.html): 109 capturas únicas,
  busca, detalhes expansíveis, ampliação de imagens e impressão.
- [Pacote ZIP entregue](sinergica-entregas.zip): cópia dos dois arquivos acima.

O HTML incorpora as imagens e pode ser aberto localmente após baixar/clonar o repositório.
O visualizador de código do GitHub pode mostrar apenas o código-fonte do HTML.

As capturas foram feitas na aplicação local com código da referência main e backend
configurado. O documento separa implementado, condicionado, planejado e falhas observadas.
Não é evidência de homologação integral nem de que produção esteja na mesma versão.

Na observação da época, Rentabilidade e Dashboard de Atendimento apresentaram falhas.
O portal externo não foi capturado por falta de login autorizado de síndico.
Não houve correção desses problemas nem escrita de dados de negócio durante o levantamento.

QA do HTML na entrega original: 18 capítulos, 83 capacidades, 110 figuras (uma captura
reutilizada em dois capítulos), sem imagens quebradas/erros de JavaScript no teste;
busca, expansão, ampliação, Escape e navegação mobile conferidos.

Dados de contato foram mascarados nas capturas. Os materiais são internos do projeto;
nenhuma credencial, sessão de autenticação ou arquivo de ambiente integra esta pasta.
